## Status Language

| Status | Meaning |
|---|---|
| Planned | Approved for future study or implementation but not started |
| In progress | Currently being learned, designed, or implemented |
| Lab completed | Implemented and validated in the controlled lab |
| Documented | Evidence reviewed, sanitized, and explained |
| Published | Final material committed to the public portfolio |

A planned company, service, certification, architecture, or AI solution must never be presented as completed work.
